算法：二分查找

二分算法（Binary Search）的核心不仅仅是“在有序数组里找个数”，更高级的理解是：在一个具有单调性（或二段性）的区间上，通过不断的折半查找，逼近目标值。

针对你的考试准备，我将二分法拆解为标准模板和**核心思维（如何缩减范围）**两部分。

一、 二分算法的本质：二段性

不要只盯着“有序”，要盯着**“二段性”**。

只要你能找到一个判断条件（我们称为 check(x) 函数），将整个搜索区间一分为二，使得：

  • 左半边满足某个性质（比如全是红色）。
  • 右半边不满足该性质（比如全是绿色）。
  • 分界点就是我们要找的答案。

二、 一般步骤（三步走）

1. 确定搜索区间 [L, R]

这是最开始的一步。

  • 如果是数组查找，区间就是下标 [0, n-1]。
  • 如果是求某个具体的数值（二分答案），区间就是答案可能的最小值到最大值。

2. 确定 check(mid) 函数（最关键）

你需要设计一个逻辑，输入中间值 mid，返回 true 或 false。

  • 这个函数决定了你如何“砍掉”一半的区间。
  • 核心逻辑： 如果 check(mid) 成立，说明答案在 mid 的某一侧（或者就是 mid）；如果不成立，说明答案在另一侧。

3. 根据 check 的结果更新区间

这是最容易写出死循环的地方。为了避免死循环，业界通常推荐使用两套由边界行为决定的模板（C++风格，Java通用）：

三、 怎么通过观察题目来缩减范围（如何设计 Check 函数）

这是考试中最难的部分，通常称为 “二分答案” (Binary Search on Answer)。当你发现题目有以下特征时，立刻想到二分：

1. 题目特征信号

  • 关键词： “最大值最小”、“最小值最大”、“满足条件的最大/最小值”。
  • 数据范围： 答案通常是一个具体的整数，且范围较大（如 $1$ 到 $10^9$），但验证一个答案是否正确很简单。

2. 缩减范围的思维推导（以“切绳子”或“分配资源”为例）

假设题目问：“你可以得到某种资源的最大长度是多少？”

第一步：假设答案是 X

不要去想怎么直接算 X，而是想：“如果我告诉你答案就是 X，你能验证它行不行吗？”

第二步：寻找单调性（缩减范围的依据）

  • 如果 长度 X 可以满足条件，那么 长度 X-1 一定也能满足吗？（通常是的，更短更容易满足）。
  • 如果 长度 X 太长了不满足，那么 长度 X+1 一定也不满足吗？（是的）。

这就是单调性！

  • 区间 [0, Max] 被分成了两段：
    • [0, Ans]：全部 check 为 True。
    • [Ans+1, Max]：全部 check 为 False。

第三步：编写 Check 逻辑

你的任务变成了：给定一个固定的 mid，判断它是否合法。

实战案例：进击的奶牛 (Aggressive Cows)

题目：有 N 个隔间，放 C 头牛，让最近的两头牛之间距离尽可能大。求这个最大距离。

  1. 确定区间： 距离最小是 0，最大是 10^9。L=0, R=10^9。
  2. 观察单调性：
    • 假设距离是 mid。
    • 如果我们能以 mid 为间隔放下 C 头牛，那说明距离这就够了，甚至可以尝试更大的距离（答案在右边，L = mid）。
    • 如果放不下，说明 mid 太大了，必须减小距离（答案在左边，R = mid - 1）。
  3. Check(mid) 怎么写： 贪心算法。
    • 放第一头牛在起点。
    • 遍历隔间，只要当前隔间和上一头牛距离 $\ge mid$，就放一头。
    • 看最后放的牛总数是不是 $\ge C$。

3. 总结：缩减范围的口诀

  1. 定两头： 答案可能的最小值 L 和最大值 R 是多少？
  2. 猜中间： 假设答案是 mid。
  3. 判合法： 写一个 check(mid) 函数。
    • 如果 mid 满足条件，我是该往大了找（L=mid），还是往小了找（R=mid）？
    • 这决定了你用哪一套模板。
